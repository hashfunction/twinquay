TwinQuay Help

Find duplicates, review a cleanup plan, and move chosen exact duplicates into a recoverable quarantine. TwinQuay is based on dupeGuru 4.3.1 and retains its standard, music, and picture discovery tools.

Discover and review

  1. Add local folders. Mark folders as references when their files should be kept.
  2. Choose a scan mode. Standard Contents creates exact-content candidates. Filename, music-tag, folder, and picture similarity scans are review suggestions and cannot authorize cleanup.
  3. Scan, inspect each group and its reference, then mark duplicates you want to review.
  4. Choose Review Cleanup Plan… (Ctrl+D). The preview lists duplicate, reference, evidence, eligibility, bytes, and destination. Uncheck anything you want to keep.
  5. Choose a quarantine folder. Save a JSON plan if you want an independent copy. Click Verify and quarantine selected.

TwinQuay checks current metadata and reads each pair byte-for-byte immediately before moving. Changed files, links/reparse points, cloud placeholders, folders, read-only files and similarity-only candidates are refused. A scan digest alone never authorizes cleanup. Quarantine runs in a background job; cancel stops before the next item after recording the current transaction.

Receipts and restore

A quarantine contains <plan-id>/plan.json, receipt.json, and one payload folder per item. Keep the entire directory. The receipt includes original paths, exact destinations, statuses, sizes, and SHA-256 recovery checksums. Plans are also saved in TwinQuay application data.

Open Quarantine Receipts… (Ctrl+Shift+Q), select the receipt and the items you want restored. Restore checks the saved payload and refuses any occupied original path, including links. Rename or relocate your newer file yourself before retrying. Rescan after restore to refresh discovery results.

Interrupted operations: keep both source and quarantine. Open receipt.json and inspect the reported payload folder. A .staging file may be the recoverable copy. Source-retained means both copies remain. Recovery-required means inspect both paths before taking another action. TwinQuay never automatically empties quarantine or overwrites an original file. Do not edit payloads or receipts while an operation runs.

Storage and preferences

On Windows, settings, cache, and plan records use %LOCALAPPDATA%\TwinQuay. Quarantine stays in the folder you choose. Import dupeGuru scan settings explicitly through the Actions menu; the old settings remain separate, and custom commands are not imported. Saved dupeGuru results remain readable, but must be rescanned in Contents mode before cleanup.
