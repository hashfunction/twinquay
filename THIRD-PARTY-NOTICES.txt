Windows operating-system components:
The Windows package requires Windows 10 build 19041 or later. Its reviewed
freezer recipe uses the operating system's Universal CRT and 43 enumerated
API-set contracts instead of redistributing incidental SDK/JDK copies.
VC/MFC libraries remain separate redistributable inputs. Original runtime
terms and a scoped distributor reference are in notices/release-notices;
Microsoft conditions apply only to Microsoft Distributable Code.
See distribution/corresponding-source/WINDOWS-SYSTEM-LIBRARIES.md in source.

Build/documentation/test tooling and transitive versions are locked. The

credits. The distributed package inventory must be reviewed, especially Qt
