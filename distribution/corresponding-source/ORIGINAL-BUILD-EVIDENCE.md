This audit does not infer a developer's particular subscription or claim that an Authenticode signature is a license grant.

The application adds substantial functionality and preserves unmodified runtime files. A downstream distributor of an upstream application can use the developer's permitted distribution route; the terms do not require every application user to own Visual Studio. [Original redistribution list](https://learn.microsoft.com/en-us/visualstudio/releases/2022/redistribution).
